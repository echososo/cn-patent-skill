# 这个文件夹可以直接当 Obsidian 库

两种用法，选一个：

**A. 案子放这里**：把整个 `vault-template` 复制一份、改名成你的案件库（比如 `我的专利案件`），
以后每件案子一个子文件夹放进来。Obsidian → 打开其他库 → 打开本地文件夹 → 选它。
`.obsidian/graph.json` 已经配好图谱配色：权利要求蓝、区别特征紫、对比文件橙、证据绿、审查问题红；
检索轨迹那张图另有候选靛蓝、检索文献土黄、轮次灰。

**B. 案子已经在你自己的库里**：把 `.obsidian/graph.json` 里 `colorGroups` 那一段抄进
你库的 `.obsidian/graph.json`（设置 → 图谱里改一次颜色也行，一样的效果）。

图从哪来：让 agent 做完审查后跑

```
python3 obsidian/build_case_graph.py <你的案件文件夹>
```

生成 `<案件文件夹>/图谱/`，打开里面的 `案件_图谱.canvas` 看整张图，
或者用左侧的关系图谱视图看双链。检索过程那张图另跑

```
python3 obsidian/build_search_trail.py <你的案件文件夹>
```

生成 `<案件文件夹>/图谱/检索轨迹/`，双击 `检索轨迹图谱.html`（不出 canvas，图在网页里，可导出 PNG）；
`候选/`、`轮次/`、`文献/` 的双链笔记在库里照常能看。
