# 授权七道门

用于新案立项、申请充分性评审、完整初稿评审和可提交终审。局部措辞修改、纯排版和用户明确限定的单点任务不机械执行全套。

本门槛用于减少可预见的驳回风险，不能保证授权。不得把门槛状态换算成脱离检索范围的授权百分比。

## 使用方法

每道门只能标记为：

- `PASS`：已有可定位证据支持，未发现阻断性问题；
- `RISK`：存在风险，但有明确补证、改写或退守路径；
- `BLOCKED`：当前主张无法由现有证据和披露合理支撑，继续扩写会掩盖缺陷；
- `N/A`：本案确实不适用，并写明理由。

每个状态必须附：判断对象、证据位置、最强反方理由、最小补救和补救后的保护范围影响。没有证据不得标 `PASS`。完整新案存在未处置的 `BLOCKED` 时，返回检索、实验或方案选择阶段，不直接写完整申请文件。

## 门 1：新颖性

- 确认拟议申请日或优先权日前的公开范围；申请前公开另按 [申请前风险](pre-filing-risk.md) 检查。
- 对每项独立权利要求判断是否有一篇现有技术文件直接、无歧义地公开其全部技术特征及特征关系。
- 不得用多篇文献拼接否定新颖性；不得把“可能隐含”直接当作“已经公开”，除非本领域技术人员能够直接确定。
- 记录文献号、公开日、具体段落或附图以及未公开特征。

## 门 2：创造性

按现行“三步法”逐项评价：

1. 选择最接近现有技术。优先考虑与本发明实际技术问题、用途或技术效果相关联的方案，再综合共有技术特征。
2. 确定区别特征，并根据区别特征在本发明中实际达到的技术效果，客观确定实际解决的技术问题。技术问题不得包含区别手段本身或对其作出暗示。
3. 判断现有技术整体是否给出把区别特征用于最接近现有技术以解决该问题的技术启示，包括第二文献、公知常识、设计需求和有限选项。

功能上相互支持、存在相互作用并共同产生效果的区别特征要整体评价。只写“文献没有公开”不足以证明创造性；必须分析现有技术是否给出技术启示、两者技术上是否相互排斥、结合后能否得到所述效果，以及是否属于事后分析。

权利要求中对解决技术问题没有作出贡献的特征，通常不会给技术方案带来创造性。不能靠加入业务标签、用途名称、结果描述或与技术效果无因果关系的限定凑区别；必须说明区别特征实际改变了什么技术处理并产生什么效果。

## 门 3：保护客体与实用性

- 权利要求整体应当体现为解决技术问题而采用技术手段并获得技术效果，而非纯业务规则、数学方法、信息展示或主观评价。
- 算法、商业规则或模型特征只有与技术特征在功能上相互支持、存在相互作用时，才把其贡献纳入技术方案和创造性分析。
- 方案能够制造或使用并产生积极效果；依赖不可获得数据、未定义外部能力或纯愿望式目标时不得标 `PASS`。
- AI、算法和软件案件必须同时通过 [AI 与软件专利](ai-software-patents.md) 的专项核对。

## 门 4：充分公开

站在本领域技术人员角度，判断能否在不付出创造性劳动和过度试验的情况下实现权利要求覆盖的方案。至少核对：

- 输入来源、格式、边界与前置条件；
- 关键数据结构、中间表示、状态迁移、处理规则和输出；
- 参数、阈值、选择依据及必要范围；
- 异常、终止、降级和失败分支；
- 关键模块之间的接口与因果关系；
- 至少一个贯穿、可复算并能显示发明机制作用的实施例。

只证明某一个点能够运行，不当然支持更宽的概括范围。参考实现可以证明可实施性，但不能替代说明书中的清楚、完整记载。

## 门 5：权利要求支持与清楚

- 每项技术特征都能在说明书、实施例或附图中定位，且组合关系与权利要求一致。
- 功能性或效果性限定具有足够实现方式，保护范围没有超出说明书能够合理概括的边界。
- 术语、对象、步骤顺序、状态、公式和引用关系清楚；必要技术特征未被省略。
- 使用 [权项—支持矩阵](claim-evidence-matrix.md) 逐项核对。矩阵空白或只写“全文支持”不得标 `PASS`。

## 门 6：修改基础与退守能力

- 原始说明书明确披露核心方案、关键关系、优选组合、参数或分支和具体实施例，形成至少三级可用退守梯度。
- 预期组合的特征在原始文件中有明确组合依据，不能依赖申请后任意抽取不同实施例的孤立特征。
- 数值端点、优选范围、状态组合和可选分支需要退守时，应在原始申请文件中有可定位记载。
- 每条退守路线写明说明书依据、创造性作用和保护范围代价。申请后才想到、原文没有基础的特征不能作为补救方案。

## 门 7：单一性、内部一致与可答复性

- 全文围绕一个总的发明构思；多项独立权利要求之间具有相同或相应的特定技术特征，而非把无关发明塞入一案。
- 权利要求、发明内容、实施方式、摘要、附图、实验和矩阵使用同一技术链、术语和数字。
- 能够针对最强新颖性、创造性、客体和充分公开攻击形成至少一条不修改答辩路线和一条有原始依据的最小修改路线。
- 完整初稿按 [模拟审查](examiner-simulation.md) 验证可答复性。

## 输出模板

```markdown
| 门槛 | 状态 | 核心判断 | 证据位置 | 最强反方理由 | 最小补救 | 范围影响 |
|---|---|---|---|---|---|---|
| 新颖性 | PASS/RISK/BLOCKED/N/A |  |  |  |  |  |
```

结论只采用：`进入撰写`、`补证后进入`、`返回方案阶段`、`按用户限定继续但保留风险`。最后一种仅在用户知情决定后使用。

- [国家知识产权局：《专利审查指南》（2023）修改解读（三）](https://www.cnipa.gov.cn/art/2024/1/18/art_2199_189864.html)：创造性三步法及实际技术问题的确定。
- [国家知识产权局：2025年《专利审查指南》修改内容解读](https://www.cnipa.gov.cn/art/2025/12/4/art_66_202935.html)：AI、大数据案件的客体、创造性和充分公开要求。
