# 演练案例 04：废旧磷酸铁锂正极材料的选择性提锂

> 虚构演练案例。工艺方案、实验数据、文献号、日期全部是编的，只用于演示本技能包的产物形态，不构成任何真实技术或法律主张。

废旧磷酸铁锂黑粉提锂，常规做法是加氧化剂把二价铁氧化掉，锂就从晶格里出来。难点是加多少：加少了锂捞不干净，加多了铁跟着溶、渣变细还夹带锂。更麻烦的是来料批批不一样——有的没放透电、本来就脱了一部分锂，有的黏结剂残留多、碳自己吃氧化剂。按固定配方投料必然翻车。

本案的做法：先拿小样在两个设定电位下做氧化滴定，把"还剩多少二价铁"和"碳要吃多少氧化剂"分开量出来；再用这两个数**算出**在线控制的三个判据（投多少、平台走多长、平台电位落在哪个窗口）；然后分批投加，用浸出液氧化还原电位的平台形态判终点，平台电位一偏出窗口就按偏移量重算碳耗补偿系数、切小批量补投。前一步的测定值真的改写了后一步的判据和状态迁移，不是两道工序排排坐。

**这个案子专门演示化学案件怎么处理充分公开和数值范围支持。** 软件案件写不清顶多啰嗦，化工案件写不清直接被打回：权利要求里写"过量系数 0.02–0.08"，审查员就要问凭什么是这两个端点。本案给了 3 个实施例、1 个对比例，外加一张范围端点考察表——每个受保护的范围，端点内外各一组数据。`04`、`05` 两份产物里充分公开和支持写得最厚，正面回答这个问题。
