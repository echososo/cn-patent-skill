# 权利要求 1（独立）

> 一种日志告警抑制方法，其特征在于，包括：接收告警消息并提取来源与标题； 将标题中的 UUID、时间戳和数字替换为通配符后计算哈希，得到告警指纹； 判断该指纹是否存在有效的抑制窗口；若不存在，则推送该告警并开启新窗口， 窗口长度按照告警等级的基础窗口乘以退避倍数的连续吵闹次数次幂确定，并以上限值封顶； 若存在有效窗口且本条告警等级不高于窗口等级，则不推送并将计数器加一； 若存在有效窗口且本条告警等级高于窗口等级，则立即推送、提前结算当前窗口并按新等级重开窗口； 窗口关闭时若计数器大于零则补发摘要消息；所述窗口状态存储于 Redis 中， 所述方法通过 /api/v1/alerts 接口接收告警，所述 suppress_window_sec 参数可配置。
