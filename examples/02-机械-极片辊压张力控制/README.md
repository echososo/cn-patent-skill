# 机械行业完整演练：极片辊压机的张力控制

## 这个案子讲什么

锂电池极片过辊压机被压实的时候会变长一点，所以收卷要比进料转得快一点点。现在的设备把这个"快一点点"写成一个固定值，来料厚度一变就跟不上，张力不是冲上去就是松下来，轻则跑偏起皱，重则断带。

本案的做法是：出口装不下测厚仪，那就用辊缝设定值加上"轧制力把辊系顶开的量"反推极片在辊缝里的厚度，据此实时估出延展率，前馈修正收卷速度。但光有前馈还不够——真正的发明点在两处协同：**前馈量变化得太快时，反过来把张力环的积分冻住**（因为这时候的张力偏差本来就是前馈自己造成的过渡过程，积分再管一次就是重复作用，过渡完了会反向超调）；**解冻之后积分往哪边走，又反过来去修正前馈模型里的辊系刚度**。前馈估计不可信时也不是一刀切掉，而是按张力还剩多少裕度分档慢慢卸，卸掉多少就同步补进积分项，切换瞬间速度给定不跳。

## 跑两个脚本（不用模型，几秒钟）

```
python3 obsidian/build_search_trail.py "examples/02-机械-极片辊压张力控制"
python3 scripts/check_patent_package.py "examples/02-机械-极片辊压张力控制/02-申请文件.md"
```

第一个在 `图谱/检索轨迹/` 下生成一个双击即开的网页，看得见哪个候选在哪一轮被谁打掉。

第二个报 **3 个 ERROR、0 个 WARN**，退出码 1。三个 ERROR 全是 `placeholder-figure`，说的是说明书里那三段 mermaid 围栏还没渲染成图片——本包的约定是围栏属草稿态，提交稿必须先出 PNG。跑一次 `scripts/mermaid_render.py` 就归零，这件事本身也被记进了模拟审查报告的 `FORM-01`。
