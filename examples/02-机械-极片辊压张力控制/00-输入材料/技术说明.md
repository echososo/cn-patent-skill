# 辊压机张力这块的情况说明（给专利那边看的）

写于 2026-06-16，设备工艺组，口述整理，没来得及排版，先发过去。

## 一、设备是个什么东西

我们这条线是负极极片的辊压工序。上游涂布烘干完的极片卷过来，我们把它压实，压完再送到分切。

从头到尾：放卷 → 张力浮辊 → 上游测厚仪 → 一对轧辊（就是辊压的主辊）→ 出料 → 收卷。
放卷和收卷各一台伺服，轧辊自己也有主传动。张力传感器装在收卷前面那个导辊的轴承座上，
测的是辊压出口到收卷这一段的张力。

主辊那边有：
- 辊缝设定，液压压下，能设到负值（就是预压，两个辊先压紧一点）；
- 压力传感器，测轧制力，两侧各一个，我们取平均；
- 轧辊自己的线速度用编码器；
- 收卷侧也有编码器。

上游测厚仪是 β 射线的，装在轧辊入口前面大概 0.85 米的位置（这个数是安装图上量的，实际可能差个几厘米）。
出口这边**没有装测厚仪**。当初想装，位置不够，而且极片出辊以后还要回弹，测出来的也不是辊缝里那个厚度。
这一点很关键，后面说。

## 二、现在的控制是怎么写的

现在跑的是老版本控制器，逻辑很简单：

1. 张力设定值按极片规格查表。比如 600 宽的负极片，表里写 0.20 N/mm，乘出来就是 120 N。
   换个牌号换个表。
2. 张力传感器读数进来，跟设定值比，偏差送 PI，PI 的输出去修收卷电机的速度给定。
3. 收卷速度给定 = 轧辊线速度 × (1 + 一个固定的超前比例) + PI 输出。
   那个固定超前比例是当初调试的时候试出来的，负极现在填的是 1.0%，正极填 0.6%。
   工艺换配方了就手动改。
4. 完了。没别的了。

这个"固定超前比例"是整个事情的病根。它其实是在补偿极片被压完以后变长了这件事——
出料比进料快，你收卷不多转一点，料就堆在中间了。但它是个**固定值**。

## 三、遇到的问题

### 3.1 主要问题：厚度一变，张力就炸

极片来料的厚度不是恒定的。涂布起停的地方、换卷接头附近、还有涂布本身的横纵向波动，
都会让来料厚度跳。我们记录过，一个典型的台阶是从 180 μm 跳到 196 μm，
过渡段很短，大概 0.3 米（按 60 米/分钟跑就是 0.3 秒），基本就是个台阶。

厚度一变，压下去以后的延展就变了。厚的地方压得更狠，延展更多，出料更快。
但是收卷速度给定里那个 1.0% 是固定的，跟不上。于是：
- 延展变大而收卷没跟上 → 料多出来 → **张力掉**，掉狠了极片在导辊上就跑偏、起皱；
- 反过来延展变小 → **张力冲上去**，冲狠了会把涂层拉出暗裂，严重的直接断带。

张力环当然会去调，但是慢。张力传感器本身有滤波，浮辊有惯量，收卷侧转动惯量又大
（满卷的时候一卷几百公斤），从张力开始偏到 PI 把它拉回来，实测要 1.5 秒往上。
这 1.5 秒里料已经跑过去 1.5 米了。

我们量过，纯反馈的时候厚度台阶处张力峰值偏差能到设定值的 ±18%（120 N 的设定，偏到 142 N 和 98 N），
恢复要 1.6 秒。工艺那边给的带宽是 ±10 N，也就是 ±8%，明显超了。

### 3.2 试过的办法

**试过一：把 PI 调猛一点。** 比例增益往上加。结果是厚度台阶那里确实反应快了点，
但是平稳段开始振荡，张力在设定值上下来回晃，晃到工艺那边来投诉极片表面有横纹。退回去了。

**试过二：把那个固定超前比例改成按牌号分几档。** 也就是查表查得更细。
没什么用——问题不是牌号之间的差别，是**同一卷极片内部**厚度在变。查表解决不了卷内的波动。

**试过三：拿上游测厚仪的读数直接去改超前比例。** 这个思路是对的，我们试了两周。
公式用的最土的办法：超前比例 = 常数 × (来料厚度 / 名义厚度)。效果有一点点，但是不稳：

- 时机对不上。测厚仪在轧辊上游 0.85 米，它现在读到的这段料，要 0.85 秒以后才进辊缝
  （60 米/分钟的话）。我们一开始是读到就用，等于提前了 0.85 秒去改速度，
  结果张力反而在厚度还没到辊缝的时候就先动了一下，白扰动一次。后来加了个固定延时，好一些，
  但是**升降速的时候又对不上了**——起车的时候线速度从 0 爬到 60，那个延时根本不是固定的。
- 更根本的是，我们其实不知道压完以后是多厚。出口没测厚仪。只知道辊缝设的是多少，
  但辊缝设定值不等于实际辊缝——压上去以后整个辊系会被顶开，轧制力越大顶开越多。
  这个"顶开"的量老张说轧钢那边有公式，是轧制力除以机架刚度，我们这台没标定过。

**试过四：让前馈一直在线。** 就是不管信号好不好都用。有一次测厚仪脏了，
读数飘到一个离谱的值，前馈直接把收卷速度给定往上顶了一大截，当场断带。
从那以后前馈这一路就被工艺锁了，现在还是纯反馈在跑。

### 3.3 还有一个没解决的怪现象

试办法三的时候，我们发现一个事：厚度台阶**过去以后**，张力反而会往反方向偏一下。
台阶那会儿张力先往上冲，等台阶跑完了、料又平稳了，张力会往下掉个 10 来牛，再慢慢回来。

老张说这是 PI 的积分在台阶那段憋进去的量，台阶过去了它还没吐出来。
我们没想到怎么办。把积分限幅试过，限死了平稳段的静差又下不来。

## 四、我们自己的想法（不一定对）

1. 那个"顶开量"能不能算出来。轧钢那边的公式我们抄过来试试，但机架刚度得标定。
   老张说可以用不同轧制力下的辊缝实测反推，标出来大概 4 kN/μm 这个量级。
2. 厚度变化和延展变化的关系不是线性的。极片压下去主要是把涂层里的孔压掉，
   真正变长的部分很少。我们粗略算过，厚度压掉 25%，长度只多了 1% 出头。
   所以不能拿厚度比直接当延展率用，得有个折算系数。这个系数跟配方有关，
   同一个配方应该是稳的，可以标定。
3. 测厚仪的信号该不该信，得有个判断。至少数据别太旧、辊缝别跳变、轧制力别超范围。
   但是这几条只能挡住明显的坏数据，挡不住"数据看着正常但算出来的延展率是错的"这种情况。
4. 前馈万一不能信了，不能一下子撤掉。上次断带就是相关的道理——控制量突变本身就是个扰动。

## 五、还没做的

- 机架刚度没标定，现在只有老张估的 4 kN/μm。
- 那个折算系数（厚度减薄里有多少变成了长度）只在负极 A 配方上粗算过一次。
- 升降速时的延时对齐，只是想到了，没写代码。
- 第 3.3 节那个反向偏差，完全没有解决方案。
- 前馈可信度怎么判，只有第 4 点那三条硬检查的想法。
