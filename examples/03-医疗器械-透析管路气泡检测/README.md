# 演练案例 03：透析管路气泡检测与分级处置（医疗器械 + 信号处理）

## 讲什么

透析静脉管路上夹着超声气泡检测器，现在通行的做法是回波幅值掉过固定阈值就停泵夹管。可这个基线本身不稳：
血细胞比容高、探头贴合度变了，基线就漂，高比容病人被反复误停泵；反过来，一串单个都够不着阈值的微气泡又会全漏。

本案让同一探头交替发两个频率，把两路回波的对数幅值拆成**共模量**和**频率差分量**。气泡挡声路是宽带的，
两个频率一起掉、差分量不动；血液和耦合的变化是频率相关的，差分量会动。于是用差分量在线重标定阈值，
再用"下降够不够平坦"校验事件是不是气泡，然后按单泡体积和累积量在记录／减速排气／停泵夹管三档间迁移。
档位反过来收紧阈值，降速反过来改体积估计的流速——几个机制互相咬住，不是排成一队。

## 这个案子专门演示怎么处理第 25 条客体风险

专利法第 25 条第一款第（四）项把"疾病的诊断和治疗方法"排除在授权之外，写在透析机上的方法很容易被这条挡回来。
本案通篇按"体外循环管路上的气泡检测与设备控制方法"来写：测的是管腔里的气体和液体，不是人体状态；
控的是泵和阀，不是治疗处方。想看这套技能怎么正面处理客体风险，直接看 `04` 的客体那一门和 `05` 的 OBJ 一栏。
