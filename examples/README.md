# 示例：四个行业，四套完整产物

这不是"输入材料样例"，是**跑完整条流程之后的成品**。不用装任何东西，在 GitHub 上直接点开就能看。

四个案子全部虚构——技术方案、实验数据、文献号、日期都是编的，只用来演示这个技能包产出什么形态的东西。

|---|---|---|---|---|
| [`demo-case/`](demo-case/) | 软件 / 运维 | **一份故意写坏的稿子**，埋了 12 个坑，用来练"专利审查" | — | 4 轮 / 7 篇 |

## 后三个案子里各有什么

每个案子的目录长得一样，按数字顺序就是这件案子实际走过的路：

| 文件 | 是什么 |
|---|---|
| `00-输入材料/` | 工程师给的原始材料——粗糙、不完整、有口语，**故意写成真实材料的样子** |
| `01-技术交底书.md` | 给代理人看的那一份。固定七章 + 末尾一节「附：证据状态」，逐条标清哪些是材料里本来就有的、哪些是技能替他补写的 |
| `02-申请文件.md` | 权利要求书 + 说明书 + 摘要。附图用 ```mermaid 围栏写，**GitHub 上直接渲染成图** |
| `02-申请文件-定稿.md` + `mermaid_figures/` | 同一份稿子跑过 `mermaid_render.py` 之后：围栏换成 PNG，形式检查 ERROR=0 |
| `02-申请文件-定稿.docx` | 再跑 `md_to_docx.py` 出的 Word：宋体正文、页脚页码、附图嵌进去。**点开就能交给代理所** |
| `03-检索轨迹台账.md` | 固定格式的五张表：候选、轮次、查询式、文献、对照 |
| `图谱/检索轨迹/检索轨迹图谱.html` | 上面那张台账画成的图。**下载后双击就能开**，力导向图 + 四列流程图，能导出 PNG |
| `04-权项证据矩阵与授权七道门.md` | 每条权项的每个限定追到哪份材料；七道门逐门 PASS / RISK / BLOCKED；退守梯度 |
| `05-模拟审查报告.md` | 逐项法定审查，每个问题给「位置 — 问题 — 最小修改」，末尾附驳回压力测试视角找到的最致命攻击路径和对它的反驳 |

## 这四份产物是怎么来的

对着装好技能的 agent 说人话就行，一句一份：

```
专利交底书：examples/02-机械-极片辊压张力控制/00-输入材料/
专利撰写：examples/02-机械-极片辊压张力控制/00-输入材料/
专利审查：examples/02-机械-极片辊压张力控制/02-申请文件.md
专利检索图谱：examples/02-机械-极片辊压张力控制/
```

图谱那一条其实就是跑一条命令，你现在就能复现：

```bash
python3 obsidian/build_search_trail.py examples/02-机械-极片辊压张力控制
```
